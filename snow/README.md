# Snow overlay

Постоянная анимация частиц поверх окна AyuGram Desktop: снег, сакура, матрица,
дождь, осенние листья.

У AyuGram Desktop нет системы плагинов (открытый апстрим-issue
[#230](https://github.com/AyuGram/AyuGramDesktop/issues/230)), поэтому эффект сделан
не внутри клиента, а отдельным layer-shell окном на Quickshell. Окно с пустым
input-регионом, то есть кликов не перехватывает, и по умолчанию показывается только
пока окно AyuGram в фокусе.

## Запуск

Автозапуск уже прописан в `~/.config/niri/config.d/30-startup.kdl`, отдельным
`spawn-at-startup` — своим процессом, а не внутри yoake, чтобы затык в анимации
не утащил за собой бар и уведомления.

Руками:

```
qs -p ~/.config/quickshell/snow/shell.qml
pkill -f 'snow/shell[.]qml'
```

Скобки в паттерне не косметика: без них `pkill -f` совпадает с командной строкой
самого вызывающего шелла и убивает его вместе с оверлеем.

## Настройки

Всё живёт в `config.json` рядом с `shell.qml`. Файл под наблюдением, изменения
подхватываются на лету — перезапуск не нужен.

| ключ              | значение                                            |
| ----------------- | --------------------------------------------------- |
| `enabled`         | эффект включён                                       |
| `type`            | `snow`, `sakura`, `matrix`, `rain`, `leaves`         |
| `count`           | число частиц на экране                               |
| `speed`           | множитель скорости падения, `1.0` — обычная          |
| `size`            | множитель размера частиц                             |
| `opacity`         | `0..1`                                               |
| `sway`            | боковой снос по синусоиде                            |
| `spin`            | вращение частиц                                      |
| `onlyOverAyuGram` | показывать только когда AyuGram в фокусе             |
| `appId`           | app_id окна, к которому привязка                     |
| `layer`           | `top` (по умолчанию), `overlay`, `bottom`            |

Правится руками или командой `snow` (симлинк на `snowctl` в `~/.local/bin`):

```
snow                  показать текущие настройки
snow sakura           сменить тип, без слова type
snow count 80
snow speed 1.5
snow only off         частицы на весь рабочий стол, а не только над AyuGram
snow toggle
```

`layer: "overlay"` поднимает частицы поверх полноэкранных окон; `top` их не трогает.

## Типы частиц

Параметры каждого типа (глиф, цвет, базовый размер, время падения, амплитуда сноса,
период вращения, наклон) заданы в `presets` в `shell.qml`. Матрица собирается из
случайной катаканы отдельно для каждой колонки, поэтому одинаковых столбцов не бывает.

Дождь — единственный тип, который рисуется не глифом, а прямоугольным штрихом:
у глифа длина фиксированная, и капля выходила одинаковой у всех. Капля летит вдоль
своего наклона (`drift` считается через тангенс `tilt`), а не падает отвесно, будучи
повёрнутой; наклон у каждой свой в пределах пары градусов. Длина, толщина, яркость
и скорость завязаны на общий `rdepth` — ближняя капля длинная, яркая и быстрая,
дальняя короткая, бледная и медленная. Вдоль штриха идёт градиент: хвост
растворяется, голова остаётся плотной.

Из-за сноса спавн идёт по ширине `width + |drift| + amp` со сдвигом влево, а не по
голой ширине окна. Иначе в нижнем углу со стороны сноса остаётся клин шириной
`tan(tilt) * высота` (при 11 градусах на 1080p — больше 200 px), куда не попадает
ни одна капля.
